## Publish your profile README

1. Sign in to GitHub, or create an account at https://github.com/signup.
2. Open your profile and select **Edit profile**. Paste the name, bio, and location above, then save.
3. Open https://github.com/new. Set the owner to your personal account and name the repository **exactly the same as your GitHub username**. For example, if your username is `nikhilkalia-chemistry`, use that as the repository name.
4. Choose **Public**, enable **Add a README file**, and create the repository. If that repository already exists, open it instead.
5. Open the repository's `README.md`, select the pencil/edit action, and replace its contents with the supplied `README.md` file's contents. Use the **Preview** tab to check the layout.
6. Upload the entire `assets` folder alongside `README.md` at the repository root using **Add file → Upload files**. Keep the folder named `assets` so the animation and badges load. Choose **Commit changes** and commit to the default branch. A suitable commit message is `Add chemistry and AI quality profile`.
7. Visit `https://github.com/YOUR-USERNAME`, replacing `YOUR-USERNAME` with your actual username. Your README should appear on your profile.

GitHub requires a public repository matching your username and a nonempty `README.md` in its root. No GitHub Pages deployment, hosting service, or coding setup is required.

Official instructions: [Managing your profile README](https://docs.github.com/en/account-and-profile/how-tos/profile-customization/managing-your-profile-readme).
